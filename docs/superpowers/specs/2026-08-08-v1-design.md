# AuditCheck v1.0 Design

**Status:** approved direction (user chose bar 3: installable PWA + polish + EDGAR ticker backfill)  
**Date:** 2026-08-08  
**Current version:** 0.2.0

## Goal

Ship a production-ready **1.0.0**: installable offline-capable PWA, honest compliance UX, hardened rendering, documented data refresh, and substantially better portfolio ticker coverage via SEC EDGAR name join — without becoming a compliance system or adding frameworks.

## In scope

1. **Ticker backfill** — build-time join of empty `ticker` fields against SEC `company_tickers.json` by normalized issuer name.
2. **PWA install** — `manifest.webmanifest`, icons, apple-touch-icon.
3. **Offline shell** — service worker caching app shell + hashed assets + `data.json`.
4. **First-visit disclaimer modal** — one-time `localStorage` ack; footer sentence unchanged.
5. **Modal a11y** — Escape, focus trap, restore focus (paste + disclaimer modals).
6. **Hardening** — escape/DOM-safe result rows; `doChips` tests; real `README.md`.
7. **Ops** — “Refreshing the dataset” runbook in `CLAUDE.md`; close stale GitHub issues already done in 0.2.0; bump to `1.0.0`.

## Out of scope (explicit)

- Role-based “covered person” scoping (#20)
- Family-account / indirect-interest modeling (#21)
- Analytics, auth, backend, new npm runtime deps / frameworks
- Reshaping `Row` to add CIK (name join only for v1)
- Perfect ticker coverage for funds / non-listed issuers

## Locked decisions

| Topic | Decision |
| --- | --- |
| Backfill timing | **Build-time / ops script** in `tools/backfill-tickers.mjs`, not in-browser fetch |
| Match key | Suffix-stripped lowercased name (same rules as `stripSuffixes` in `src/data.ts`) |
| Ambiguity | If ≥2 SEC titles normalize to the same key, **skip** that key (no overwrite) |
| Existing tickers | **Never overwrite** a non-empty ticker |
| Row shape | Remains `[firm, name, ticker, date]` |
| SW location | `public/sw.js` (copied to `dist/` by Vite) |
| Manifest / icons | `public/manifest.webmanifest`, `public/icons/icon-192.png`, `public/icons/icon-512.png` |
| Disclaimer copy | Footer sentence verbatim: `Always verify against your firm's internal restricted list.` |
| Deps | No new runtime frameworks; Node built-ins only for the backfill script |

## Success metrics

- Unique tickers in `t2f` after backfill ≫ current ~495 (name-match dry-run ≈ +2.8k unique empty names → expect multi-thousand tickers).
- Lighthouse: installable / offline basics (not required to score 100).
- `npm test` + `npm run build` green; package version `1.0.0`.
- Stale issues (#2, #7, #8, #12, #18, #19) closed as done; v1 issues closed when shipped.

## Non-goals reminder

The app remains a **public PCAOB proxy**, not GIMS/GMS. v1 improves match rate and packaging; it does not claim completeness.
